# 设备只读参数记录（ReadOnlyData）

连接设备后读取的 ReadOnlyData JSON 已解析到 `PressReadOnlyData`（`src/core/press_service.h`），
“关于本机”卡片展示主要参数；以下字段在设备 JSON 中存在，但上位机**尚未解析**
（如需使用，需补充结构体字段与 JSON 读取）。

| JSON 字段 | 含义 | 设备当前值 | 备注 |
|---|---|---|---|
| `Screenshot` | 截屏使能 | 0 | 0=关闭，1=开启 |
| `StartDelay` | 启动延迟（秒） | 3 | 启动流程前的等待时间 |
| `IsHideLang` | 隐藏语言切换菜单 | 0 | 0=显示，1=隐藏 |
| `Remote` | 远程控制使能 | 2 | 设备上报原始值，SDK 定义为 0~2 |
| `Network` | 网络模块使能 | 0 | 0=无网络模块，1=有 |
| `PModel` | 压力模式切换 | 0 | 设备压力控制模式 |
| `OutType` | 输出信号类型 | 0 | 设备输出接口类型 |

已用于界面显隐的字段：

- `IsHasSpeed`：0 时隐藏“升温速率”区域，并强制普通模式（不显示温度阶段“速率”列）。
- `IsHasWater`：0 时隐藏“水冷回路”区域。
- `VersionType`：0 仅单独模式，1 仅合作模式，2 双模式；不可用的模式在侧栏隐藏并禁止切换。

显示精度（已接入压力相关界面）：

- `PDecimal`：压力（Ton）显示小数位，用于压力表格“压力/补压设定”、实时压力与设定压力。
- `PressDecimal`：模具压强（MPa）显示小数位，用于“模具压强”数值。
- `TDecimal`：温度（°C）小数位，目前仅解析并在系统设置展示，温度数值暂按固定 1 位显示。

设备标识与自动补压：

- `NameZH`：设备中文名，连接成功后用于标题栏“<名称> · 上位机”和侧栏品牌名；为空时回退 `NameEN`。
- `Type`：设备型号，连接成功后替换侧栏副标题默认的 `AUTO HOT PRESS`；界面不再显示版本号。
- `Max_Min`：自动补压差（Ton）。修改某段压力后，该段补压设定自动更新为 `压力 - Max_Min`（最小 0）。

## 压力工艺参数（PressData）

已接入“压力阶段”表格、阶段数与模具类型：

- `PStep` → 阶段数（1~30）
- `SetPValue[]` → 压力列
- `AfterValue[]` → 补压设定列
- `KPTime[]` → 计时列（JSON 数值为秒，界面显示 mm:ss）
- `Type` → 模具类型（0 异形 / 1 圆形 / 2 矩形；3 环形暂未支持）
- `D` → 圆形模具直径（mm）
- `A` / `B` → 矩形模具长 / 宽（mm）

已解析但暂未展示：

| JSON 字段 | 含义 | 设备当前值 | 备注 |
|---|---|---|---|
| `CheckValue` | 校准值 | 0.0 | 0~5 |
| `AirTime` | 排气时间（秒） | 1 | 0~60 |

## 温度工艺参数（TempData）

已接入“温度阶段”表格、温度阶段数、速率模式与水温：

- `TStep` → 阶段数（1~30）
- `StartTemp[]` → 温度列
- `Speed[]` → 速率列（不支持速率模式时该列隐藏）
- `KTTime[]` → 计时列（JSON 数值为秒，界面显示 mm:ss）
- `Type` → 升温速率模式（0 普通，非 0 速率；设备不支持速率时强制普通）
- `MinWater` → 降温水温（°C）
- `MaxWater` → 升温水温（°C）

无暂未展示字段。

## 合作工艺参数（MixData）

已接入“合作流程明细”表格与合作阶段数：

- `Step` → 阶段数（1~30）
- `IsPress[]` → 是否加压
- `SetPValue[]` → 压力列
- `AfterValue[]` → 补压设定列
- `IsUpHeat[]` → 是否加热上板
- `UpTemp[]` → 上板温度列
- `IsDownHeat[]` → 是否加热下板
- `DownTemp[]` → 下板温度列
- `KTime[]` → 计时列（JSON 数值为秒，界面显示 mm:ss）
- `Type` → 合作模式模具类型（0 异形 / 1 圆形 / 2 矩形；3 环形暂未支持）
- `D` → 合作模式圆形模具直径（mm）
- `A` / `B` → 合作模式矩形模具长 / 宽（mm）

说明：合作模式模具与单独模式模具互相独立，分别对应 MixData 与 PressData 的
`Type/A/B/D`；合作模式下的修改通过 `setMixMoldType / setMixCircle / setMixRectangle`
下发。

无暂未展示字段。

## 实时数据（RealTimeData）

- `MoldPressure`：设备不再上报该字段；界面“模具压强”统一由实时压力 `PValue` 与模具面积计算：
  `PValue × 9806.65 / 面积(mm²)`（MPa），异形模具无面积时显示 `—`。
- `IsAir`：设备是否具备排气能力。为 1 时底部“排气”按钮可用，点击后下发
  `startAir`（`CMDID_SET_START_AIR` 0x1524）启动排气；为 0 时按钮禁用并提示
  “设备当前不支持排气”。本地模拟模式不下发命令，仅清空本地压力显示。
- `FlowChange`：参数变更标记。0 无操作；1 表示下位机 Press 参数 JSON 已改变；2 表示温度
  参数 JSON 已改变；3 表示合作参数 JSON 已改变。上位机收到后自动重新读取对应 JSON 并刷新界面，
  同一非 0 值只处理一次，回到 0 后重新生效。
- `PTime` / `TTime`：单位均为秒（单独模式与合作模式一致），界面按 mm:ss 显示。
- 实测合作模式曾返回 `601000`，仍按秒解析；若界面显示异常，应核查固件上报数值本身，而非单位换算。
