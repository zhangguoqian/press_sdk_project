# 自动热压机 · 上位机 UI 设计说明

> 基准参考：`机器界面/单独模式主界面.bmp`（1024 × 600 触摸屏版）
> 交付物：`自动热压机_上位机UI原型.html`（单文件可交互原型，双击即可运行）+ `预览图/`（11 张 1440 × 900 效果图）+ `src/`（可编辑源码）

---

## 1. 设计目标

原始界面是 **1024 × 600 的触摸屏 HMI**：顶部蓝色标题栏、白色圆角工作区、底部 7 个等宽大按钮。这套结构在嵌入式屏上很好用，但直接搬到桌面端会有三个问题：

| 问题 | 桌面端的后果 |
| --- | --- |
| 底部横排 7 个大按钮当导航 | 占用宝贵的垂直空间，鼠标点击路径长 |
| 1024 × 600 的信息密度 | 在 1920 × 1080 上显得空洞，操作员频繁翻页 |
| 触摸优先的大控件 | 键鼠环境下缺少悬停反馈、悬停提示、表格直接编辑 |

因此本次设计的目标是：**保留原有工业蓝的视觉基因与全部功能语义，把"触摸屏界面"重构成"上位机软件界面"**——更大的信息密度、左侧导航、常驻操作条、可读的实时曲线。

---

## 2. 从触摸屏到桌面的 6 个关键决策

1. **导航从底部改为左侧竖排**（206 px 深色导航栏）
   分组为「运行监控 / 工艺配置 / 数据 / 系统」，符合工控软件的习惯；底部腾出的空间交给**常驻操作条**。
2. **底部条改为上下文操作条**
   运行页显示「启动加压 / 启动加热 / 停止全部 / 急停」，参数页显示「恢复默认 / 保存参数 / 返回」，数据页显示「复制 / 删除 / 导出 / 返回」——与原界面底部按钮的语义一一对应，但只显示当前场景需要的。
3. **信息密度提升约 2 倍**
   原界面一屏 2 张表 + 8 个参数；新主界面同屏容纳 2 张阶段表 + 7 个参数 + 安全联锁 + 事件记录 + 实时曲线 + 运行进度。
4. **新增实时双轴曲线**
   触摸屏版只有「列表/曲线」页；桌面端把曲线提升到主界面，压力（Ton，左轴）与温度（°C，右轴）同屏对比，这是操作员判断工艺是否正常最需要的信息。
5. **安全信息显性化**
   急停按钮独立成红色八边形并带 5 px 光晕；启动动作一律走二次确认弹窗；主界面常驻「安全联锁 4/4」与告警横幅。
6. **支持键鼠精细操作**
   表格单元格可直接编辑（悬停描边、聚焦高亮），滑块、开关、步进器均为桌面控件，全部带 hover / focus 态。

## 3. 布局与栅格

**基准画布 1440 × 900**，最小 1180 × 720，两档断点（1500 / 1320）自动收窄列宽。

```
┌──────────────────────────────────────────────────────────┐
│ 标题栏 34px  应用名 · 版本 · 窗口按钮                      │
├──────────────────────────────────────────────────────────┤
│ 应用栏 58px  页面标题 / 状态胶囊 / 时钟 / 操作员           │
├────────┬─────────────────────────────────────────────────┤
│ 导航    │ 内容区  内边距 14×16，卡片间距 14                │
│ 206px  │ 三栏：330 │ 自适应 │ 428                        │
│        │                                                 │
├────────┴─────────────────────────────────────────────────┤
│ 操作条 72px  安全提示 · 主操作按钮组                       │
└──────────────────────────────────────────────────────────┘
```

- 主界面三栏比例 `330 : 1fr : 428`，与参考图的「参数列 : 双表 : 状态列」完全对应。
- 所有卡片：圆角 14 px、1 px 描边 `#E3EAF0`、双层柔和阴影，卡片头 44 px。
- 行高：键值行 42 px、表格行 44 px、表头 36 px——比触摸版（46~50 px）略紧，仍保留足够的点击热区。

## 4. 色彩系统

主色直接取自参考图 `单独模式主界面.bmp` 的采样值，保证与原有机器视觉延续。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 品牌蓝 | `#00A1E9` | 主色、图标、激活态、压力曲线 |
| 深蓝 | `#0079B4` | 数值强调、表头文字 |
| 皇家蓝 | `#0A43F6` | 次级选中（沿用原界面选中标签色） |
| 导航深色 | `#0A2334 → #08202F` | 左侧导航渐变 |
| 页面底色 | `#EDF1F5` | 内容区背景 |
| 卡片 | `#FFFFFF` | 所有卡片 |
| 成功绿 | `#00A32A`（原 `#008C1E`） | 启动加压 |
| 加热橙 | `#E8730C` | 启动加热、温度曲线 |
| 告警红 | `#C8102E` / `#8C0000` | 急停、停止、超限数值 |
| 文本 | `#12293D` / `#3B5770` / `#7B8FA1` | 主 / 次 / 辅助 |

> 相较原界面纯蓝白，新增了「深色导航」与「橙色加热」两处：深色导航建立界面层级，橙色让"热"与"压"两个子系统在视觉上可区分，符合工业界「压力=冷色、温度=暖色」的通用认知。

## 5. 字体与排版

- 中文：`Microsoft YaHei UI / PingFang SC`
- 数字：`Bahnschrift`（Windows 自带工业感字体），全部启用 `tabular-nums`，数字跳动不抖动
- 字号层级：页面标题 17 / 卡片标题 13.5 / 正文 12.5 / 表头 11.5 / 单位 10.5 / 关键数值 23（键值行）、15.5（表格数字）、30（时间步进）
- 单位一律用弱化的 10.5 px 灰字跟随标签（`设定压力 (Ton)`），不干扰读数

## 6. 组件规范

| 组件 | 规格 |
| --- | --- |
| 卡片 | 圆角 14、描边 `#E3EAF0`、阴影 `0 1px 2px + 0 2px 6px`（6% 透明度） |
| 键值行 | 左标签（单位弱化）+ 右数值（23 px 等宽）；实时项数值为品牌蓝并在标签前加呼吸圆点 |
| 表格 | 表头浅蓝底 `#E9F7FE` + `#0B6EA8` 字；当前阶段行整行浅蓝渐变 + 3 px 左侧色条 + 序号变实心蓝 |
| 主按钮 | 高 46、圆角 10、125° 双色渐变 + 顶部 1 px 高光 + 同色投影 |
| 急停 | 红色八边形图标 + 5 px 外光晕，独立于其他按钮的视觉重量 |
| 确认弹窗 | 420 px 宽、圆角 16、背景模糊遮罩，左「返回」右「确认」，危险操作用红色主按钮 |
| 状态胶囊 | 高 27、圆角 20、浅底，内置 7 px 状态点（在线绿 / 运行蓝呼吸 / 报警红） |
| 图表 | 自绘 Canvas：5 条水平网格、圆角折线、数据头圆点 + 光晕、渐变面积填充、双 Y 轴 |

## 8. 交互与安全逻辑

- **启动加压 / 启动加热**：二次确认弹窗，文案包含段数、首段/末段目标值与安全提醒；确认后顶部胶囊、表格当前行、进度条、曲线同步进入运行态。
- **停止全部**：橙色警示弹窗，确认后所有进度归零。
- **急停**：红色危险弹窗；执行后顶部出现红色告警横幅「急停已按下」，操作条提示切换为「急停生效」，并在解除前禁止再次启动。
- **参数编辑**：修改即校验（模具压强由「压力 ÷ 模具面积」实时换算：φ100 mm、1.0 Ton → 1.25 MPa），未保存时点「保存参数」才写入 PLC，并有 toast 提示。
- **状态一致性**：所有数值由同一状态机驱动，主界面、合作模式、进度条、曲线共享同一数据源（原型中内置一套加速仿真的 PLC 数据）。

## 9. 交付与落地建议

- 原型为**单文件 HTML/CSS/JS**，无外部依赖、无网络请求，可直接双击在浏览器或内嵌 WebView 中打开；`?/#/flow` 形式的 hash 可直达任意页面（`#/settings/time` 等）。
- 上机时可选用 **Electron / Tauri** 直接封装该前端，或按同一套 token 移植到 **Qt(QSS) / WPF**：
  - 颜色、圆角、间距、字号均已抽为 CSS 变量（`--brand`、`--r-lg`、`--font-num` 等），可直接映射为主题表；
  - 图表为自绘 Canvas，Qt 端可用 `QPainter` 按同一套坐标规则复刻。
- 建议分辨率 1920 × 1080（125% 缩放），触摸屏工位也兼容（按钮最小热区 44 px）。
